# sql-exploratory-data-analysis-layoffs
SQL based exploratory data analysis of a global layoffs dataset to identify trends, patterns, and key business insights.

## Project Overview
This project focuses on performing exploratory data analysis (EDA) using SQL on a real world global layoffs dataset. 
The objective was to analyze layoff trends, identify impacted industries and regions, and uncover patterns over time 
to support data-driven insights.

The analysis was performed on a cleaned dataset to ensure accuracy and reliability of results.

## Dataset
- Source: Kaggle – World Layoffs Dataset (2022)
- Link: https://www.kaggle.com/datasets/swaptr/layoffs-2022
- Format: CSV
- Description: Company-level layoff data including industry, location, date, funding, and company stage information

## Analysis Performed
- Analyzed total layoffs across companies, industries, and countries
- Identified trends in layoffs over time
- Examined industry-wise and region-wise impact
- Compared layoffs by company stage and funding levels
- Derived summary statistics to highlight key patterns

## SQL Concepts Used
- Aggregate Functions (SUM, COUNT, AVG)
- GROUP BY and HAVING
- ORDER BY
- Date Functions
- Filtering and Conditional Logic
- Exploratory Data Analysis (EDA)

## Outcome
The analysis highlights major layoff trends, most affected industries and regions, and time-based patterns.
These insights can support workforce planning, market analysis, and business decision-making.

## How to Use
1. Load the dataset into your SQL environment
2. Run the queries in the SQL script sequentially
3. Review result sets to interpret trends and insights
